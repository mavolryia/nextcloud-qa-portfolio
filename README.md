# Тестирование Nextcloud Files

Учебный QA-проект: ручное тестирование приложения «Файлы» в [Nextcloud Server](https://github.com/nextcloud/server) на локальном стенде.

## Стенд

- Nextcloud 35.0.2 (до 2026-11-11 версия 34.0.5), MariaDB 11.4, Docker Compose, Windows 11
- Браузер: Google Chrome
- Инструменты: Qase (чек-листы и прогоны), Postman (WebDAV API), curl
