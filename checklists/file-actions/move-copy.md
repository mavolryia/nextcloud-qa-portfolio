# Действия с файлом: перемещение и копирование

| № | Шаг | Данные |
|---|---|---|
| 1 | Переместить файл через «Move or copy» → «Move»; убедиться, что файл пропал из исходной папки и появился в новой | report.txt → «Отчёты» |
| 2 | Скопировать файл через «Move or copy» → «Copy»; убедиться, что файл остался в исходной папке и появился в новой | photo.jpg → «Архив» |
| 3 | Изменить копию, убедиться, что оригинал не изменился | копия photo.jpg |
| 4 | Скопировать файл в ту же папку; убедиться, что копия получила другое имя, а оригинал не перезаписан | photo.jpg |
| 5 | Переместить файл в папку, где уже есть файл с таким именем; убедиться, что файл не перезаписан молча и система предлагает выбор, какой файл оставить | report.txt |
| 6 | Переместить несколько файлов сразу | 3 файла → «Архив» |
| 7 | Перетащить файл на папку в списке; убедиться, что файл переместился, а не скопировался (пропал из исходной папки) | photo.jpg → «Отчёты» |
| 8 | Перетащить файл на папку, где уже есть файл с таким именем; убедиться, что файл не перезаписан молча и система предлагает выбор, какой файл оставить | report.txt |
| 9 | Перетащить несколько выделенных файлов на папку | 3 файла → «Архив» |
