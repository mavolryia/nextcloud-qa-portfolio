# Действия с файлом: теги

| № | Шаг | Данные |
|---|---|---|
| 1 | Создать тег и назначить его файлу через Manage tags | report.txt, тег «Проект» |
| 2 | Убедиться, что тег отображается у файла | report.txt |
| 3 | Открыть раздел Tags, найти файлы по тегу | «Проект» |
| 4 | Снять тег с файла | report.txt |
| 5 | Создать тег из 64 символов латиницы | 64 × a |
| 6 | Создать тег из 65 символов латиницы; убедиться, что имя обрезано до 64 символов | 65 × a |
| 7 | Создать тег из 32 букв кириллицы | «я» × 32 (64 байта) |
| 8 | Создать тег из 33 букв кириллицы; убедиться, что имя обрезано до 32 букв | «я» × 33 (66 байт) |
| 9 | Создать тег, у которого 64-й байт приходится на середину буквы; убедиться, что имя не испорчено: нет «битого» символа в конце | «a» + «я» × 40 |
| 10 | Создать тег из 17 эмодзи; убедиться, что имя обрезано до 16 эмодзи | 🙂 × 17 (68 байт) |
| 11 | Создать тег, отличающийся от существующего только регистром; убедиться, что второй тег не создан | «проект» при существующем «Проект» |
| 12 | Создать два тега, различающихся только после 64-го символа; убедиться, что второй тег не создан | 64 × a + «1», затем 64 × a + «2» |
| 13 | Создать тег только из пробелов; убедиться, что тег не создан | «   » |
| 14 | Создать тег с пробелами в начале, в конце и несколькими подряд; убедиться, что тег сохранён как «мой тег» | «  мой   тег  » |
| 15 | Создать ограниченный тег, убедиться, что user1 видит его, но не может назначить или снять | admin создаёт тег «Restricted» |
| 16 | Создать невидимый тег, убедиться, что user1 его не видит | admin создаёт тег «Invisible» |
| 17 | Запретить создание тегов всем, кроме администраторов; убедиться, что user1 не может создать тег | admin: настройка совместных тегов. После проверки вернуть |
