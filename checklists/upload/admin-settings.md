# Загрузка файлов: настройки администратора

| № | Шаг | Данные |
|---|---|---|
| 1 | Запретить расширение и загрузить файл с ним; убедиться, что загрузка отклонена | forbidden_filename_extensions + .exe; setup.exe |
| 2 | Открыть, скачать и переименовать файл с запрещённым расширением, загруженный до запрета | setup.exe, загруженный до запрета |
| 3 | Включить режим совместимости с Windows и загрузить файл с ? в имени; убедиться, что загрузка отклонена | windows_compatible_filenames = true; a?b.txt |
| 4 | Запретить базовое имя и загрузить файлы с ним в разном регистре; убедиться, что загрузка отклонена | forbidden_filename_basenames = secret; secret.txt, SECRET.pdf |
