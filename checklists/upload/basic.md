# Загрузка файлов: основной сценарий

| № | Шаг | Данные |
|---|---|---|
| 1 | Загрузить файл через «+ Новый → Загрузить файлы» | report.txt |
| 2 | Загрузить файл перетаскиванием из Проводника в список файлов | photo.jpg |
| 3 | Убедиться, что во время загрузки отображается индикатор прогресса | Файл ~300 МБ, чтобы успеть увидеть прогресс |
| 4 | Убедиться, что загруженный файл есть в списке, а имя и размер совпадают с исходным | report.txt |
| 5 | Открыть загруженный файл | report.txt, photo.jpg |
| 6 | Скачать загруженный файл и сравнить его хеш с хешем исходного | photo.jpg; `Get-FileHash <файл>` в PowerShell |
| 7 | Открыть окно выбора файла, нажать «Отмена» и убедиться, что ничего не загрузилось |  |
