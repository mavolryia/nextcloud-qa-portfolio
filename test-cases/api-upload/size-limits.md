# Лимиты размера

## TC-108. Загрузить файл 100 МиБ одним запросом PUT

**Предусловия:**  
Кто: user1, Basic Auth с паролем приложения (окружение Postman NextcloudLocal).  
Данные: файла 104857600.bin в корне нет.  
Настройки: по умолчанию (правила имён по умолчанию, режим совместимости с Windows выключен).

| № | Шаг | Данные | Ожидаемый результат |
|---|---|---|---|
| 1 | Отправить PUT, в Body (binary) выбрать файл | /remote.php/dav/files/user1/104857600.bin<br>Файл: 104857600.bin (104 857 600 байт) | Код 201 Created. В заголовках ответа есть ETag и OC-FileId |
| 2 | Проверить, что файл создан: отправить PROPFIND с заголовком Depth: 0 | /remote.php/dav/files/user1/104857600.bin | Код 207 Multi-Status. getcontentlength = 104857600 |

**Постусловия:** Удалить созданный файл: DELETE /remote.php/dav/files/user1/104857600.bin, очистить корзину.

## TC-110. Загрузить файл 512 МиБ + 1 байт (лимит PHP на WebDAV PUT не действует)

**Описание:** Лимит PHP относится к загрузке формой (POST). WebDAV PUT передаёт файл потоком, поэтому файл больше лимита PHP принимается.

**Предусловия:**  
Кто: user1, Basic Auth с паролем приложения (окружение Postman NextcloudLocal).  
Данные: файла 536870913.bin в корне нет.  
Настройки: по умолчанию (правила имён по умолчанию, режим совместимости с Windows выключен); upload_max_filesize = 512M.

| № | Шаг | Данные | Ожидаемый результат |
|---|---|---|---|
| 1 | Отправить PUT, в Body (binary) выбрать файл | /remote.php/dav/files/user1/536870913.bin<br>Файл: 536870913.bin (536 870 913 байт) | Код 201 Created. В заголовках ответа есть ETag и OC-FileId |
| 2 | Проверить, что файл создан: отправить PROPFIND с заголовком Depth: 0 | /remote.php/dav/files/user1/536870913.bin | Код 207 Multi-Status. getcontentlength = 536870913 |

**Постусловия:** Удалить созданный файл: DELETE /remote.php/dav/files/user1/536870913.bin, очистить корзину.

## TC-112. Попытка загрузки файла 1 ГиБ + 1 байт (больше лимита Apache)

**Описание:** Postman на этом запросе зависает: он не отправляет заголовок Expect: 100-continue. Выполнять через curl: curl -u user1:&lt;пароль> -T 1073741825.bin &lt;адрес>.

**Предусловия:**  
Кто: user1, Basic Auth с паролем приложения (окружение Postman NextcloudLocal).  
Данные: файла 1073741825.bin в корне нет.  
Настройки: по умолчанию (правила имён по умолчанию, режим совместимости с Windows выключен); LimitRequestBody = 1 ГиБ.

| № | Шаг | Данные | Ожидаемый результат |
|---|---|---|---|
| 1 | Отправить PUT через curl -T | /remote.php/dav/files/user1/1073741825.bin<br>Файл: 1073741825.bin (1 073 741 825 байт) | Код 413 Request Entity Too Large. Тело файла не передаётся (curl: передано 0 байт). Ответ: HTML-страница Apache |
| 2 | Проверить, что файл не создан: отправить PROPFIND с заголовком Depth: 0 | /remote.php/dav/files/user1/1073741825.bin | Код 404 Not Found |
